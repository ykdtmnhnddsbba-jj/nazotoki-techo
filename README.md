# 謎解き手帖 — セットアップ手順

参加した謎解き（リアル脱出ゲーム等）の **感想・結果・面白さ・教訓** を溜めていくための個人用データベースです。
`index.html` 1ファイルだけで動く静的サイトで、費用はかかりません。

## 1. 公開する（GitHub Pages）
1. このリポジトリの Settings → Pages
2. Source を `Deploy from a branch`、Branch を `main` / `(root)` にして Save
3. 1〜2分後に `https://<ユーザー名>.github.io/nazotoki-techo/` で開ける

## 2. 使い方
メニューは時間の流れで4つに分かれています（右端の ⚙ が設定）。
- **これから**: 参加予定の公演・周遊と、日付を入れた購入系の予定。「1か月以内」と「すべての予定」（日付が過ぎた予定・日付未定も含む）を切り替えられます。チケットURL・地図・カレンダー登録・「✔ 参加済みにする」がここにあります。チケット未登録の予定があるとタブに ⚠ が付きます。
- **買い物**: 購入系（持ち帰り・Web謎など）の予定。「買う予定」と「手元にある（未プレイ）」に分かれ、件数と合計金額が出ます。「✔ 買った」で手元へ、「✔ 遊んだ」で実績へ移ります。価格と購入ページのURLは編集画面で入れられます。
- **探す**: 謎ログから取ったオススメ（愛知・岐阜・三重）。「予定に入れる」でこれから／買い物に追加。
- **実績**: 参加済み・プレイ済みの記録。サブタブで **記録**（結果と面白さ1〜10をワンクリックで付ける・検索・絞り込み）／**成績**（成功率・連勝・団体別/形式別/月別）／**教訓**（教訓を横断検索）を切り替えます。記録は「区分（公演/周遊/購入系）」と「形式」で絞り込めます。
- **＋ 追加**: 開いているタブに合わせて初期値が変わります（これから＝予定、買い物＝購入予定・持ち帰り型）。
- **⚙ 設定**: Google Drive 連携、JSONの書き出し/読み込み、AI用プロンプトのコピー、謎ログ連携の手順。

## 3. データの保存先
記録は **このブラウザ（localStorage）** と **あなたのGoogle Drive** にだけ保存されます。リポジトリには入りません。
評価は **公開サイトのURL** で付けてください（ローカルでHTMLを直接開くと保存先が別になります）。

## 4. Google Drive に自動保存する
アニメ手帖と同じ OAuth クライアントID を埋め込み済みなので、通常は設定不要です。
1. 「設定」タブ → **連携 / 今すぐ同期**（初回は Google の確認画面。「未確認のアプリ」と出たら 詳細 → 移動）
2. 以後、保存のたびに Drive の `nazotoki-db.json` に自動保存されます（アクセス権は `drive.file`＝このアプリが作ったファイルのみ）
3. 初回だけ Drive のトップにファイルができるので、好きなフォルダへ移動してください（以後も名前で見つかります）

別のクライアントIDを使う場合は、Google Cloud で Drive API を有効化 → OAuth クライアントID（ウェブ）を作成し、承認済みJavaScript生成元に `https://<ユーザー名>.github.io`（パスなし）を追加。同意画面がテストモードならテストユーザーに自分のGmailを追加します。テストモードでは約7日ごとに右上の「☁ 要再接続」から再接続が必要です。

## 5. 他のAIに渡す／移行する
- 「設定」→ **AI用プロンプトをコピー** をAIに貼り付けると、全記録つきで傾向分析を依頼できます。
- 「JSONを書き出す」で得た `nazotoki-db.json` は先頭の `_readme` に項目説明が入っています。
- 「JSONを読み込む」は統合です（同じ公演は新しい更新を優先。既存の記録は消えません）。

## 6. 謎ログ（nazo.site）に反映する
手帖が正本です。謎ログには **作品・日付・時刻・ステータス（成功/失敗/参加済み/予定）だけ** を **非公開** で反映します（感想・評価・教訓は送りません）。変更のある記録には一覧に「未反映」が付き、ヘッダーの「謎ログに反映（件数）」で一括反映できます。
1. 初回だけ、「謎ログに反映」の画面にある ⭐リンクをブックマークバーへドラッグして登録（ブックマークレット）
2. 手帖の「謎ログに反映」→「謎ログを開く」（新しいタブで謎ログ。サインインしておく）
3. そのタブでブックマークレットを押す → 確認画面で作品の一致を確認して「実行」
4. 結果が自動で手帖に戻り、「未反映」が消えます
- 非公式のAPIを使うため、謎ログ側の仕様変更で動かなくなることがあります。1件ごとに間隔をあけて処理します。
- 作品名が謎ログと違う場合は、確認画面の候補から選べます（選ばなければスキップ）。
- 謎ログの既存記録の取り込みは、取り込み用JSON（個人データのため公開リポジトリには入れていません）を「JSONを読み込む」で読み込みます。

## データ形式（nazotoki-db.json）
```json
{
  "_readme": "...説明...",
  "schema_version": 1,
  "updated_at": "ISO8601",
  "records": {
    "<ID>": {
      "title": "公演名", "group": "団体", "date": "2026-02-21",
      "result": "大成功 | 成功 | 失敗 | (空)", "score": 8,
      "time": "16:30", "status": "plan | (空=参加済み)",
      "format": "ホール型", "venue": "会場・場所",
      "impression": "感想", "lesson": "教訓",
      "nazolog_content_id": "謎ログの作品ID", "nazolog_record_id": "謎ログの記録ID",
      "nazolog_plan_status": "defined | tentative | unreleased（予定のとき）",
      "nazolog_synced_at": "ISO8601", "nazolog_sig": "反映済みの内容の署名（未反映の判定用）",
      "created_at": "ISO8601", "updated_at": "ISO8601"
    }
  }
}
```
- `score` は面白さ（1〜10、0は未評価）。
- 削除した記録は `deleted: true` が付き、同期で別端末にも反映されます。
- 競合は `updated_at` が新しい方を採用して自動統合します。
